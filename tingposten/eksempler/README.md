# Eksempelkort for skribenten

Plassholdere: fem maskinskrevne kort fra bystyremøtet 23.09.2026 som faktasjekken
godkjente uten anmerkninger (én investering, én plan med kampvotering, én strategi,
én interpellasjon, ett fritak). Planen sier at standarden skal være fem
håndskrevne kort — bytt disse ut med dine egne når de er skrevet.
